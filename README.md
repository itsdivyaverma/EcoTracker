# 🌱 EcoTracker

## Smart Waste Management System

EcoTracker is a web-based smart waste management platform that connects citizens with waste-management administrators.

Citizens can report waste issues, request waste pickups, track their complaints, and learn about responsible waste disposal. Administrators can monitor complaints, manage pickup requests, identify waste hotspots, and prioritize reports.

## ✨ Features

### 👤 Citizen Features

- User registration and login
- Persistent login/session
- Role-based access
- Waste complaint reporting
- GPS-based location
- Smart complaint priority
- Complaint status tracking
- Waste pickup requests
- Pickup request tracking
- Waste awareness guide
- EcoReuse Hub

### 🧠 Smart Waste Management

- Smart priority classification
- Duplicate report detection
- Incident grouping
- Suspicious report detection
- Incident report counting
- Waste hotspot detection
- Geographic complaint analysis

### 🛠️ Admin Features

- Admin dashboard
- Complaint management
- Search and filtering
- Filter by status and priority
- Complaint status updates
- Pickup request management
- Waste insights and charts
- Waste hotspot monitoring

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Supabase
- Recharts
- Lucide React

## 🗄️ Backend & Database

EcoTracker uses **Supabase** for shared application data including:

- Complaints
- Waste pickup requests
- Waste incidents
- Incident report counts

Local storage is used for user/session handling.
